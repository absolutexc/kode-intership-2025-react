# KODE Internship 2025 — Frontend

Макушин Артемий

Тестовое задание на стажировку KODE. Ссылка: https://github.com/Hexlet/ru-test-assignments/blob/main/frontend/kode/trainee-test-frontend.md

## Декомпозиция

1. Инициализировать Vite + react-ts, установить react-router-dom, axios.
2. Типы и маппинг департаментов.
3. API-слой (axios, getUsers).
4. Хук загрузки + состояния loading/error.
5. Top App Bar: поиск, кнопка сортировки, вкладки.
6. Список пользователей + карточки.
7. Фильтрация по вкладкам, поиск (от 2 символов), сортировка.
8. Модальное окно сортировки.
9. Роут деталей `/users/:id`, кнопка назад, tel:.
10. Состояние «Ничего не найдено», «Критическая ошибка».
11. Адаптивная вёрстка.
12. README, финальные коммиты.

## Что сделано

- Проект на Vite + React + TypeScript.
- Загрузка списка сотрудников с API Stoplight через axios.
- Top App Bar: поиск, кнопка «Сортировка», панель вкладок департаментов.
- Фильтрация по вкладкам (клиентская, по полю `department`).
- Поиск по имени, фамилии и нику (от 2 символов).
- Модальное окно сортировки: «По алфавиту» / «По дню рождения», закрывается после выбора.
- Сортировка по дню рождения с блоком года.
- Страница деталей как отдельный роут `/users/:id`, доступна по прямой ссылке, кнопка «Назад», `tel:` для телефона.
- Состояния: загрузка, «Критическая ошибка» (API/сеть) с кнопкой «Повторить», «Ничего не найдено».
- Адаптивная вёрстка (десктоп + мобильный).

## Что не сделано

- Real-time отслеживание сети — не хватило времени, основная часть приоритетнее.
- Кэширование запросов на 5 минут — не реализовано.
- Тёмная тема — не реализована.
- Локализация — не реализована.
- Публикация на GitHub Pages — не реализовано.

## Как запустить

0. Что нужно установить заранее

| Программа | Версия | Где взять |
|---|---|---|
| Node.js | 18 или новее (LTS) | https://nodejs.org |
| npm | идёт вместе с Node.js | — |
| Git | любая актуальная | https://git-scm.com |

Проверить, что всё установлено, можно в терминале:

```bash
node -v
npm -v
git --version
```

Если команды выводят версии — можно переходить к следующему шагу.

1. Клонировать репозиторий

```bash
git clone https://github.com/_your_login_/kode-intership-2025-react.git
cd kode-intership-2025-react
```

2. Установить зависимости

```bash
npm install
```

Эта команда скачает React, React Router, Axios и остальные пакеты из package.json в папку node_modules. Занимает 1–2 минуты.

3. Запустить проект в режиме разработки

```bash
npm run dev
```

Откройте ссылку на локальный сервер в браузере — приложение загрузит список сотрудников с API Stoplight.

Остановить сервер: Ctrl+C в терминале.

## Тест-кейсы

- Все вкладки департаментов переключаются, список фильтруется.
- Поиск «an» (2 символа) фильтрует, «a» (1 символ) — нет (по ТЗ).
- Сортировка «По алфавиту» и «По дню рождения» меняет порядок; в режиме ДР отображается блок года.
- Клик по карточке открывает /users/<id>, кнопка «Назад» возвращает на главную.
- Прямая ссылка http://localhost:5173/users/<id> открывается.
- Несуществующий id → «Сотрудник не найден».
